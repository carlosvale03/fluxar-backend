# CLAUDE.md

## Specs

- As specs ficam em `.specs/` deste repositório e valem também para o frontend, que está em `../fluxar-frontend`.
- Cada spec descreve o comportamento correto, não o atual. A auditoria em `docs/auditoria-2026-09.md` é o material de origem.
- Specs em português, com as palavras-chave EARS em inglês (`SHALL`, `WHEN`, `IF`, `WHILE`, `WHERE`) e IDs sem acento, como `SALDO-01`.
- Antes de escrever uma spec, leia as decisões em `.specs/STATE.md`. Toda decisão que afete mais de uma feature vai para lá.
